# Interview Transcript: 플랜앱 교학상장 소통창구

## Q1. 소통 공간 형태
**Q:** 소통 공간을 채팅(실시간 메시지)과 게시판(비동기 글+댓글) 중 어떤 형태로 만들고 싶으신가요?
**A:** 게시판 위주 (에브리타임처럼)

## Q2. 친구 초대 범위
**Q:** 친구 초대 범위는 어떻게 되나요? 같은 반(그룹) 학생들끼리만? 아니면 다른 반/학원의 학생도 초대 가능?
**A:** 같은 학원 내 다른 반도 가능

## Q3. 학습 현황 공유
**Q:** 학습 현황 공유는 구체적으로 어떤 데이터를 공유하고 싶으신가요?
**A:** 사용자가 선택적으로 공유할 항목 지정

## Q4. 게시판 구조
**Q:** 게시판 구조는 어떻게 구성하고 싶으신가요?
**A:** 반(그룹)별 게시판 + 전체 게시판

## Q5. 멘토 참여
**Q:** 멘토(선생님)도 게시판에 참여할 수 있나요?
**A:** 멘토도 전체 참여 가능

## Q6. 익명성
**Q:** 게시글에 익명/닉네임 기능이 필요한가요?
**A:** 닉네임 사용

## Q7. 콘텐츠 형태
**Q:** 게시글에 사진/이미지 첨부 기능이 필요한가요? 문단 서식 지원은?
**A:** 리치 텍스트 + 사진

## Q8. 교학상장 연동
**Q:** 교학상장(서로 가르치기) 기능을 게시판과 어떻게 연결하고 싶으신가요?
**A:** 별도 기능 없이 자연스럽게

## Q9. XP 보상 연동
**Q:** XP/보상 연동은 어떻게 하고 싶으신가요?
**A:** XP 연동 안 함

## Q10. 모더레이션
**Q:** 게시판 모더레이션(신고/삭제) 기능이 필요한가요?
**A:** 멘토 삭제권 + 신고 기능

## Q11. UI 위치
**Q:** 이 소통창구를 기존 플랜앱 내에 탭으로 추가할건지, 별도 모듈로 만들건지?
**A:** 기존 탭에 추가 (소통 탭)

## Q12. MVP 범위
**Q:** MVP로 먼저 만들고 싶은 핵심 기능은 무엇이고, 나중에 추가할 기능은?
**A:** 전체 기능 한번에
