  <action>
Modify the `renderMath()` function in `public/modules/records/core/utils.js` to add a one-time console warning when KaTeX is not loaded. Change lines 84-86 from:

```javascript
export function renderMath(text) {
  if (!text || typeof text !== 'string') return text || '';
  if (typeof katex === 'undefined') return text;
```

To:

```javascript
export function renderMath(text) {
  if (!text || typeof text !== 'string') return text || '';
  if (typeof katex === 'undefined') {
    if (!renderMath._warned) {
      console.warn('[KaTeX] Library not loaded. Math formulas will display as plain text.');
      renderMath._warned = true;
    }
    return text;
  }
```

Do NOT change any other part of the function (the regex replacements, katex.renderToString calls, etc. remain exactly as-is). Do NOT change call ordering -- that is Phase 2 scope.
