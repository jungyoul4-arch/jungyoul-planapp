    **records.css** (COV-02):
    Add KaTeX mobile overflow CSS at the end of the file, scoped under `.archive-module` per project CSS convention:

    ```css
    /* KaTeX mobile overflow prevention */
    .archive-module .katex-display {
      overflow-x: auto;
      overflow-y: hidden;
      -webkit-overflow-scrolling: touch;
      padding: 4px 0;
    }

    .archive-module .katex-display > .katex {
      white-space: nowrap;
    }

    /* KaTeX formula copy selection UX */
    .archive-module .katex {
      user-select: all;
      -webkit-user-select: all;
    }
    ```

    IMPORTANT: Use `overflow-y: hidden` alongside `overflow-x: auto` to prevent the known KaTeX vertical scrollbar bug (per Research Pitfall 3).
